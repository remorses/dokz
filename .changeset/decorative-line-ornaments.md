Add three new `decorativeLines` ornament styles. Besides `lines-with-dots`, you can now use `lines-with-crosses` (small `+`), `lines-with-x` (small `x`), and `lines-with-circles` (small hollow ring). Each ornament keeps the same gap from the lines as the dots:

```json
{
  "decorativeLines": "lines-with-crosses"
}
```
